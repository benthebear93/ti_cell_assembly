# TI Cell Assembly

This repository currently contains one Python project:

- `surface_estimator_ur5e/`: UR5e surface estimation, MuJoCo scene export, and tray/presser simulation tooling.

Use the project from that directory:

```bash
cd surface_estimator_ur5e
uv sync
uv run surface-estimator --help
```

See [surface_estimator_ur5e/README.md](surface_estimator_ur5e/README.md) for the full workflow.
